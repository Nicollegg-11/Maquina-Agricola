# Maquina-Agricola
Este proyecto consiste en desarrollar una aplicación de escritorio en Java para gestionar y planificar los turnos de trabajo de maquinaria agrícola. El sistema permite registrar tractores, organizar las tareas según su prioridad, calcular el consumo estimado de combustible y controlar los tiempos de uso y las necesidades de mantenimiento.

# Objetivo
Aplicar los conceptos de estructuras de datos, programación orientada a objetos y computación matemática para solucionar una necesidad de planificación en el sector agropecuario.
